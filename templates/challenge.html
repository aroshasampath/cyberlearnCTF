{% elif challenge.id == 3 %}

message.txt Encoded Payload • Cryptographic Challenge
Download message.txt

Progressive Hints

Hint 1: Layered Transformation

The visible text is an encoded representation of another string.

Hint 2: Outer Layer

The outer layer is commonly used to represent binary or textual data using printable ASCII characters (Base64).

Hint 3: Inner Cipher

After Base64 decoding, the message is still protected with a Caesar cipher using a shift of 5.

{% elif challenge.id == 5 %}

Network traffic was captured during a suspicious investigation session. Analyse the packet capture, identify the relevant conversation, and recover the hidden investigation marker.

traffic_capture.pcap Packet Capture File • Wireshark / Network Analysis
Download traffic_capture.pcap

Progressive Hints

Hint 1: Filter Traffic

Not every packet in the capture is relevant. Start by identifying the protocols and conversations present in the traffic.

Hint 2: Web Requests

HTTP traffic may contain a useful investigation request with parameters or headers.

Hint 3: Follow TCP Stream

Locate the investigation-related HTTP request and use Follow TCP Stream in Wireshark to reconstruct the complete conversation.

stage06_evidence.zip Server Logs & Sudoers • Privilege Escalation Target
Download stage06_evidence.zip

Progressive Hints

Hint 1: Linux User Audit

Begin by identifying the Linux user accounts contained in the evidence package. Some service accounts may have different privileges from normal users.

Hint 2: Sudoers Configuration

Review the privilege-related configuration carefully. Ask yourself whether any account has been granted more privilege than it actually requires.

Hint 3: Sudo Execution History

After identifying the suspicious account, search the authentication log for activity associated with that account. A privileged command may reveal the path of the final evidence file.
